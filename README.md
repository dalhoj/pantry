# Pantry v0.6.9.1
Fokuseret rettelse oven på v0.6.9: automatisk indkøb vurderes nu pr. konkret produkt på tværs af produktets batches, ikke pr. produkttype. Makrel og tun under Dåsemad påvirker derfor ikke, om sidste Tomatpasta tilføjes til indkøbslisten. Produktets minimum_stock bruges fortsat som tærskel. Ingen dubletter på aktiv indkøbsliste.
